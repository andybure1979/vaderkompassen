# Väderkompassen

Väderkompassen är ett väderbaserat beslutsstöd som hjälper användaren att svara på frågan **”Vart ska jag åka idag?”**

## Version 14.0.5

Den här versionen inför en frivillig engångsprovperiod för Premium. Nya konton börjar som Gratis. Provperioden startas aktivt av användaren, gäller i tre dagar och övergår därefter till Premium om den automatiska förnyelsen inte avslutas.

Se `docs/SETUP.md` för driftsättning och migreringsordning.
