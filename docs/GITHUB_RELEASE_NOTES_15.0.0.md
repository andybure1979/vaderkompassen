# Väderkompassen 15.0.0

Den första publika huvudversionen samlar aktivitetsbaserade väderrekommendationer för Sverige, Norge och Danmark.

- Jämför väder i topplista och karta.
- Se relevanta faktaboxar och förklarande texter för varje aktivitet.
- Välj bland bland annat sol och bad, kust, surf, båt, fiske, cykling, vandring, skidor, bio och badhus.
- Free innehåller dagens prognos och en region åt gången.
- Premium är förberett för fler prognosdagar, flera regioner, utökat platsregister, molnsynk och reklamfritt.
- Konton, säker kontoborttagning och nativegrund för iOS och Android ingår.

Prognoser är beslutsstöd och ersätter inte officiella varningar eller lokala säkerhetsbedömningar.
