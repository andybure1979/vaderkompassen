# App Preview – 30 sekunder

Format: stående telefon, riktig releasebuild, svensk master och engelsk lokaliserad version. Ingen finger-overlay behöver visas om den skymmer information.

| Tid | Bild | Text/röst |
|---|---|---|
| 0–3 s | Väderkompassens startsida | ”Vad vill du göra?” |
| 3–7 s | Välj exempelvis Vandring | ”Välj aktivitet.” |
| 7–12 s | Topplistan laddas och vinnaren visas | ”Jämför var vädret passar bäst.” |
| 12–17 s | Svep över faktaboxar och flera platser | ”Se relevanta väderfakta och tydliga betyg.” |
| 17–21 s | Öppna kartan | ”Hitta alternativen på kartan.” |
| 21–25 s | Tryck Navigera till och visa systemvalet utan att lämna persondata | ”Navigera med kartappen du föredrar.” |
| 25–29 s | Öppna Premiumjämförelsen | ”Premium visar fler dagar, regioner och platser – reklamfritt.” |
| 29–30 s | Appikon och namn | ”Väderkompassen.” |

Använd butikens verkliga produktpris om pris visas. Visa inte ”offline” om scenen inte faktiskt använder appens befintliga offlinebeteende. Musik, typsnitt och all grafik måste vara licensierade för kommersiell butiksanvändning.
