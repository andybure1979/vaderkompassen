# Driftstart Väderkompassen v13.10.0

1. Publicera hela webbrotens innehåll.
2. Driftsätt Cloudflare Workern från `cloudflare/` om Worker-versionen också ska uppdateras.
3. Ingen Supabase-migrering krävs.
4. Töm eventuell CDN-cache och öppna appen på nytt så att service worker hämtar v13.10.0.
5. Kontrollera att vinnaren visar 4–12 mått i rader om fyra och att `Visa detaljer` samt topplistekorten öppnar detaljsidan.
