# Testkonton för butiksgranskning

Skapa kontona utanför Git och ange uppgifter endast i App Store Connect/Play Console.

| Konto | Behörighet | Syfte |
|---|---|---|
| Free | Free | Dagens prognos, en region och Free-annonsflöde |
| Premium | Riktig sandbox-/licenstestprenumeration | Alla dagar, flera regioner, utökat register, molnsynk, reklamfritt |
| Admin | Separat admin-entitlement | Adminvyn samt Premiumåtkomst; ska inte fabricera butiksköp |

Review Notes ska ange hur konto skapas/loggas in, var Premium och återställ köp finns, var kontot raderas samt om annonssystemet är fail-closed. Testkontona ska vara beständiga under hela granskningen, sakna MFA-hinder om butiken inte kan hantera dem och aldrig återanvända Andreas privata lösenord.
