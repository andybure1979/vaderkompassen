# Driftstart v13.8.0

## Omfattning

Denna version förnyar kartan visuellt utan att ändra prognos-, ranking- eller filterlogik.

- Pastellbehandlad kartbakgrund.
- Poängbubblor med värdet direkt på kartan.
- Vinnaren markeras tydligare.
- Nya kompakta informationskort vid tryck på en plats.
- Ny statuslegend och tydligare kartknappar.
- Kartan visar högst 75 rankade platser för god prestanda.

## Driftsättning

1. Publicera frontendfilerna på GitHub Pages.
2. Driftsätt Cloudflare Workern eftersom versionsnumret är uppdaterat.
3. Rensa eller uppdatera PWA-cachen om en äldre version visas.
4. Kontrollera att sidfoten visar **Väderkompassen v13.8.0**.
5. Öppna kartan och kontrollera att poängbubblor, popupkort och kartnavigering fungerar.
