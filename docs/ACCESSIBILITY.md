# Tillgänglighet – RC-underlag

Kodgranskning visar semantiska knappar, formulärlabels, dialogrubriker, statusregioner, text tillsammans med färgstatus och responsiv layout. Native WebView stöder systemets textskalning; fokusordningen följer DOM.

Manuellt före butik: WCAG-kontrast i ljus layout, 200 % text, tangentbord och synlig fokusmarkering, dialogfokus/fokusretur, VoiceOver på iOS, TalkBack på Android, alla kart- och faktakontroller, touchytor minst cirka 44×44 pt samt fel utan enbart färg. Dark mode erbjuds inte och ska inte utlovas. Kartans tredjepartsinnehåll och komplexa topplistor är kända områden för manuell hjälpmedelsgranskning.
